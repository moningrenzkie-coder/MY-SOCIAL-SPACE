# Rejosiah Agua Moning — personal link page

A responsive, phone-inspired personal landing page with an interactive 3D background and profile card. It is a static site and needs no build step.

## Personalize the page

In `index.html`, update the sample social URLs and details:

- Instagram, Facebook, TikTok, and YouTube profile URLs (`yourusername`)
- WhatsApp and Contact phone number (`639123456789`; digits only, with country code)
- Email address (`hello@example.com`)
- The tagline and the short copy beneath **My Background**

The RA monogram is a custom inline logo that can be recolored in `styles.css`. The phone and WhatsApp links currently use a sample number, and the email uses a sample address.

## Publish

Upload `index.html`, `styles.css`, and `script.js` together to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. There is no build command. Connect a custom domain through your chosen host. Google Fonts load online; fallback fonts are included.
